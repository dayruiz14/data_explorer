# Explorador automático de datos 📊

## Descripción
Aplicación web desarrollada en **Streamlit** que permite a cualquier usuario cargar un archivo de datos (CSV, XLSX, XLS) y realizar automáticamente un análisis exploratorio de datos sin necesidad de conocimientos avanzados de programación.

## Funcionalidades
- Carga de datasets en formatos CSV, XLSX y XLS.
- Indicadores generales: filas, columnas, duplicados y valores faltantes.
- Resumen de tipos de variables.
- Detección y visualización de duplicados.
- Análisis de valores faltantes con tabla y gráfico.
- Estadísticas descriptivas para variables numéricas y categóricas.
- Distribuciones con histogramas, diagramas de caja y gráficos de barras.
- Correlaciones con matriz y mapa de calor interactivo.
- Detección de valores atípicos mediante IQR.
- Filtros interactivos por fecha, categorías y valores numéricos.
- Tabla ordenable e interactiva.
- Descarga de datos filtrados y valores atípicos.

## Formatos admitidos
- CSV
- XLSX
- XLS
